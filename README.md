# QuantLens · macOS 原生量化看盘

[![CI](https://github.com/dujianhua200/QuantLens/actions/workflows/ci.yml/badge.svg)](https://github.com/dujianhua200/QuantLens/actions/workflows/ci.yml)

A 股 / 港股 / 美股 / 指数的本地量化看盘工具，**Swift + AppKit + Core Graphics** 原生开发，
零第三方依赖，图表全部自绘。

核心能力：**今日机会榜**（日线 + 分时 + 竞价三源合成，顶部情绪温度计）、**开盘扫描**（多标的机会排行）、**AI 复核买点**、**风险提示**、**支撑位/压力位**、**主力进场/撤退**。

## 一、GitHub 调研结论

动手前把成熟方案摸了一遍（GitHub API 实测星标/语言）：

| 项目 | ★ | 语言 | 关系 |
|---|---|---|---|
| [akshare](https://github.com/akfamily/akshare) | 23.3k | Python | 免费数据接口的事实标准。**数据源思路来自它**，但是 Python 库不是看盘软件 |
| [Sequoia-X](https://github.com/sngyai/Sequoia-X) | 8.7k | Python | A 股形态扫描 + 推送。**信号逻辑可参考**，是脚本不是 GUI |
| [MyTT](https://github.com/mpquant/MyTT) | 2.9k | Python | 通达信公式移植。**指标口径参照它** |
| [PanWatch](https://github.com/TNT-Likely/PanWatch) | 2.5k | Python | AI 股票监控，偏通知 |
| [akquant](https://github.com/akfamily/akquant) | 2.6k | Python | 量化研究框架，重回测轻看盘 |
| [stockstats](https://github.com/jealous/stockstats) | 1.5k | Python | pandas 技术指标库 |
| [watchdog](https://github.com/Hong-Chen-web/watchdog) | 2 | HTML | 唯一 macOS 原生（AppKit）方案，2 星，工程不完整 |

**结论：没有可直接用的「macOS 原生 + 四类信号」成品。** 数据层在 Python 生态成熟，信号层散落脚本，界面层 Swift 几乎空白 → 走自研。

## 三、开盘扫描（核心功能）

`Core/ScanEngine.swift`。针对「短线交易机会多但时间少」，扫描解决三件事：

1. **并发拉取**全部自选股（受控并发 3，批次间隔 180ms 防限流）
2. 对每只跑完整信号引擎，算**可比较的机会分**
3. 给出**入场区间、止损位、目标位、风险收益比、结论分级**

实测：16 只股票 12.7 秒。

### 机会分算法

以「正向信号强度」为基底，而不是从 0 分加减（否则正向信号本身只有 20~60 分时永远低分）：

```
基底 = max(买入分, 进场分) × 0.55        // 最多 55 分
买入与进场同时 ≥45            +12        // 共振
趋势：强涨+14 / 涨+8 / 震荡0 / 跌-10 / 强跌-22
盈亏比：≥3.0 +20 / ≥2.0 +14 / ≥1.5 +6 / <1.0 -18
风险拖累 = 风险分×0.42 + 撤退分×0.55     // 比例折扣，不是一票否决
止损宽度：>8% -20 / >6% -10 / ≤4% +4
RSI>80 -15；距压力<1.5% -12
```

### 结论分级（五档）

| 分级 | 条件 |
|---|---|
| **强烈推荐** | 机会分≥62 且 盈亏比≥2.0 且 风险分<60 |
| **可买入** | 机会分≥48 且 盈亏比≥1.5 且 风险分<70 |
| **观察** | 机会分≥34 |
| **无机会** | 其它 |
| **回避** | 撤退分≥60 / 趋势强下跌 / 止损>8%（硬否决，优先级最高） |

实测 16 只 A 股的分布：2 可买入、4 观察、8 无机会、2 回避 —— 不过度乐观，也不一刀切。

## 四、实时短线买点榜（短线实时）

`Core/IntradaySignals.swift` + `UI/BuyPointBoardPanel.swift`。针对「短线机会稍纵即逝」，
开盘扫描一天一次不够用，买点榜在盘中持续刷新：

1. **盘中自动轮询**：交易时段内每 60 秒扫描全部 A 股自选股的分时数据，
   每批 3 只并发、批次间隔 180ms，与开盘扫描同一套防限流约束；
   非交易时段自动停（A 股 9:30–11:30 / 13:00–15:00 北京时间，周末排除），不空转
2. **新触发置顶高亮**：同一标的的同一类触发跨轮次识别，首次出现的时间记为触发时间，
   10 分钟内的新触发置顶并高亮；触发消失即下榜
3. **触发依据可见**：每行显示触发类型、触发时间、最近支撑位与距支撑距离，
   首条触发的完整依据显示在榜单下方；点行预览看图（不加入自选）

### 分时触发类型（`IntradayTriggerKind`）

| 触发 | 方向 | 条件（全部基于逐分钟分时点 + 均价线） |
|---|---|---|
| 回踩均价 | 买 | 15 分钟内跌破均价线不超过 1.5% 后收回线上方，且相对踩点回升超 0.1% |
| 突破新高 | 买 | 现价创新高（超前高 0.1%）且近 5 分钟量比 ≥1.5 |
| 放量上攻 | 买 | 近 5 分钟量比 ≥2.0 且 10 分钟上涨 ≥0.5% |
| 均线下弱势 | 卖 | 现价在均价线下 0.2% 以上，近 10 分钟 ≥8 根在均价线下，10 分钟跌 ≥0.3% |
| 高位滞涨 | 卖 | 处于日内 85% 高分位，放量 ≥1.5 倍但 10 分钟涨幅 <0.2% |
| 跌破新低 | 卖 | 现价创新低（破前低 0.1%）且近 5 分钟量比 ≥1.3 |
| V 型反转 | 买 | 6 分钟内急跌超 1.5% 后收回均价线上方、相对低点回升超 0.8%；杀跌段缩量加分（恐惧） |
| 二次回踩 | 买 | 25 分钟内两次独立跌破均价后收回，第二次踩点抬高、现价在均价线上方；第二踩点缩量加分（恐惧） |
| 横盘突破 | 买 | ≥10 分钟在均价线 ±0.3% 内横盘后，现价站上均价线 +0.2%~+1.0% 且近 5 分钟量比 ≥1.3（已大幅拉升的不算） |
| 量价加速 | 买 | 近 10 分钟涨 ≥0.8%、后 5 分钟高点高于前 5 分钟、前 5 分钟均量 ≥全天均量 1.2 倍、后 5 分钟均量再 ≥前 5 分钟 1.3 倍、现价未创新高（贪婪） |
| 尾盘抢筹 | 买 | 14:45–15:00，10 分钟涨 ≥0.6%、近 5 分钟量比 ≥1.8、现价处日内 80% 高分位；理由注明追高风险（贪婪） |

数据口径：分时点来自腾讯 `minute/query`（已有接口，不新增端点）；
均价线是累计成交额 / 累计成交量，即成交量加权均价（VWAP）；
量比口径与 `LocalAnalyst` 一致（最近 N 分钟均量 / 全天每分钟均量）。
分时点不足 10 个时不输出触发，不产生假信号。

### 情绪引擎：把贪婪与恐惧量化（`Core/EmotionEngine.swift`）

市场情绪不是感觉，是横截面宽度算出来的分数。输入只有两条已有口径，
不新增任何接口：

| 口径 | 样本 | 字段 |
|---|---|---|
| 竞价池排行（主口径） | 约数百只 | 新浪排行行的涨跌幅 / 现价 / 昨收 / 高低价 |
| 自选快照（兜底） | 自选 A 股 | 腾讯批量快照的现价 / 昨收 / 高低价 |

```
贪婪分量 = 涨停占比×300 + 强势股(>3%)占比×120 + 正平均涨幅×8 + 上涨占比×20，上限 100
恐惧分量 = 跌停占比×300 + 弱势股(<-3%)占比×120 + 负平均涨幅×8 + 下跌占比×20，上限 100
情绪分   = 50 + (贪婪 - 恐惧) × 0.5，钳制 0~100
```

相位：<20 **冰点** / <40 **回暖** / <60 **混沌** / ≥60 **亢奋**；
≥60 但炸板率 >35%（且涨停+炸板 ≥5 家、有高价数据）或跌停占比 >2% 时判 **退潮**
——亢奋中出现炸板与分化，获利兑现压力上升。温度计条同时显示相位解读与仓位参考
（措辞一律是"参考/观察"，不是仓位建议）。

**如实说明的降级**：连板高度无法从现有字段得到（需全市场逐只 K 线历史），
本引擎不编造，以"涨停家数 + 强势股占比"作连板动量的代理；
炸板率依赖 high 字段，字段缺失时炸板率记 0 且不参与退潮判定；
`changepercent` 缺失时用现价/昨收推算涨跌幅。池样本 <20 只时自动退回自选口径，
来源如实显示在温度计旁（"竞价池 N 只" / "自选 A 股 N 只"）。

### 恐惧 / 贪婪日线信号（`Core/FearSignals.swift`）

与四类信号独立计算、独立展示，不改动四类信号分数。每条信号带强度分与理由，
理由点明心理机制。K 线不足 30 根不输出。

| 信号 | 情绪 | 方向 | 条件（要点） | 心理机制 |
|---|---|---|---|---|
| 恐慌企稳 | 恐惧 | 买 | 前 3 日累计跌超 6% 且 ≥2 日放量杀跌，当日长下影收回、收盘在当日高位 | 恐慌盘集中宣泄后抛压衰竭，承接进场 |
| 假破位诱空 | 恐惧 | 买 | 缩量跌破有效支撑（评分≥40）后当日收回支撑上方 | 跌破吓出止损盘，收回说明破位是假的 |
| 冰点首阳 | 恐惧 | 买 | RSI<32 或百分位<12、前 3 日全跌，当日放量收阳、收盘在高位 | 冰点里第一根放量阳线，空头力竭的转折观察点 |
| 恐惧衰竭 | 恐惧 | 买 | 创 20 日新低但量能逐级萎缩、当日缩量长下影收回 | 越跌越没人卖，杀跌动能衰竭 |
| 高位滞涨 | 贪婪 | 卖 | 百分位>78、小实体、量比>1.8、长上影、涨幅<1% | 追高资金踊跃但推不动，贪婪过热 |
| 加速赶顶 | 贪婪 | 卖 | 连续 3 日涨幅加速、累计>10%、量比>2、RSI>70 | 情绪加速赶顶，斜率不可持续 |
| 涨停开板 | 贪婪 | 卖 | 触及涨停后收盘回落超 3%、量比>2.5 | 封板资金兑现，涨停被砸开 |

### 集合竞价打分升级（`Core/AuctionScoring.swift` + `AuctionScanner`）

原有打分（缺口/稳定性/量能/竞价额/市值）口径不动，叠加有界调整项（合计 ±12 分以内）：

| 调整项 | 口径 |
|---|---|
| 甜点区 | 缺口 0.5%~3% +4 分；3%~5% +1 分 |
| 兑现风险 | 缺口 >5% 且量比 <2 扣 6 分；>8% 扣 10 分 |
| 委买比 | 五档委买比 ≥30 +5 分；≤-30 扣 5 分（取自竞价采样同一行情响应的五档字段，无新接口） |
| 昨日基因 | 昨日涨停 +6；连板 ≥2 再 +4；昨日收盘站当日高位 +3（日 K 复核，见下） |
| 情绪加成 | 回暖/亢奋 +3；冰点/退潮 -3；混沌/未知 0 |

分类（榜单行按分类着色）：**甜点**（缺口 0.5%~3% + 稳定性 ≥0.8 + 量比 ≥1.5）、
**兑现风险**（缺口 >5%）、**恐慌修复**（昨日跌超 3% + 今日低开 -3%~0.5% + 稳定性 ≥0.75 + 量比 ≥1.2，
认定后 +10 分）、其余**常规**。

**昨日基因复核**：定榜时对评分前 25 名复用已有日 K 接口（40 根）提取昨日基因
（昨日涨停/连板数/昨日涨跌幅/收盘强度），分批 3 只、间隔 180ms，同一交易日内缓存复用；
低开候选未被认定为恐慌修复的一律剔除。锁定期的中间刷新不做复核（只用默认打分），
避免盘中频繁拉 K 线。

### 今日机会榜（三源合成）

原"买点榜"升级为"今日机会榜"：分时触发 + 日线恐惧/贪婪信号 + 竞价候选合成一张榜，
顶部是情绪温度计，芯片切换 全部 / 分时 / 日线 / 竞价。"全部"排序：新触发优先、
其次按强度降序。日线行取每只扫描结果分数最高的情绪信号；竞价行信号文本为分类，
备注为高开/低开幅度。榜头保留"仅供娱乐与技术研究，不构成投资建议"。

### 日内支撑与日线买卖点显性化

- **日内支撑**（`IntradayLevels`）：日内低点 / 均价线 / 昨收 / 日线最近支撑位四取一，
  取低于现价的最高者为支撑、高于现价的最低者为压力；分时图画最近一档支撑/压力虚线，
  买点榜每行显示支撑位与距离百分比。日线 `LevelEngine` 口径不动，这里只做合并与取最近。
- **日线买卖点记录**（`TradePoint`）：把 `SignalEngine` 的图上标记与当前信号转成
  显性记录（价格、触发日期、依据、所属信号类），在扫描结果行里展示最近一条买点/卖点；
  K 线图上的三角标记继续复用已有机制，不重复画。
- **与单只研判的分工**：`LocalAnalyst` 仍负责当前标的的分时研判与图上买卖标记；
  买点榜负责全自选的触发扫描。两者数据同源，结论口径各自独立，互不覆盖。

**仅供娱乐，不构成投资建议。** 触发是技术信号，不是买卖指令，买卖由人判断。

### 日线买卖点引擎（`Core/TradePointEngine.swift`）

旧标记机制是四类评分的阈值穿越：实测贵州茅台 320 根日线只打出 2 个标记（买入分最高
只到过 70 一次），图上基本没有买卖点。新引擎改为**显式形态检测**：每根 K 线按规则
逐条检验，每个点自带触发价、ATR 止损、目标位、R 值、理由与失效条件。同一标的同批数据
打点 16 个（买 3 / 卖 13），同族 5 根内冷却去重，不刷屏。

| 代码 | 形态 | 触发口径（全部只用 ≤ 当日数据，无前视） |
|---|---|---|
| B1 | 趋势模板突破 | 价在 SMA50/150/200 之上、SMA50 在上、SMA200 上行、收盘创 252 日新高、量 ≥1.5×50 日均量；止损 2×ATR 且最多 7% |
| B2 | 平台突破 | 20 日箱体振幅 ≤15%、箱内缩量、收盘破箱顶、量 ≥2×20 日均量、收盘在 MA20 上 |
| B3 | 均线回踩 | 多头排列 + MA20 上行、低点贴 MA20/MA10 后收回、缩量 <0.9 倍、收阳 |
| B4 | 动量放量 | 20 日涨幅 ≥8% 且拐头向上、量 ≥2 倍、OBV 创 20 日新高、非涨停追高 |
| B5 | N 字二波 | 一波 ≥10%、回踩 3%~20%（>20% 无效）守住 MA20、缩量、放量破整理高点 |
| B6 | 首阴反包 | ≥2 板后首阴、次日涨停且收盘 ≥ 首阴开盘、触发日开盘溢价 ≤5.5% 才触发；触发价为开盘价；**最小仓位级别，样本依据极弱（仅 7 笔回测），永不标强** |
| B7 | 超卖回归 | 仅震荡市：ADX<25 门控、触 BB 下轨收回、RSI14<30、收阳、未创 20 日新低、目标中轨 |
| S1 | 趋势破位 | 新鲜收盘破 MA20 + MA20 拐头向下 + 收盘在 MA60 下（MA60 存在时） |
| S2 | 高位兑现 | 复用 `FearSignals` 贪婪信号（高位滞涨 / 加速赶顶 / 涨停开板）转译为卖点 |
| S3 | 跌破支撑 | 新鲜收盘跌破前 20 日最低点 |

**融合与门控**：同族 5 根内冷却去重；同日 ≥2 个独立信号族标"强"（B6 除外）；
环境门控只否决不加分——指数走熊（收盘在下行 MA20 下）且市场宽度恶化（样本 ≥20 只、
上涨占比 <30%）时否决买点（图上淡化显示），卖点永不否决；任一数据缺失即放行。
图上买点红色上三角、卖点绿色下三角，带两字形态标签；恐惧/贪婪信号画小菱形
（恐惧蓝、贪婪黄）。信号面板列出最近买卖点（日线 + 当日分时触发合并，倒序），
并注明"T+1 下日内止损只是提醒，跳空可能穿止损"。

**诚实限制**：十个检测器各自有公开来源的规则依据（Minervini 趋势模板、箱体突破、
均线回踩、动量/OBV、N 字二波、首阴反包确认版、BB+RSI 均值回归、趋势破位、贪婪兑现、
支撑破位），但**组合策略未经样本外（OOS）回测验证**，不宣称任何收益或胜率。
S2 复用的 `fakeBreakdown` 用全量支撑位有轻微前视，仅作显示参考。
明确不做的：Dual Thrust 日内原版（T+1 不兼容）、海龟加仓、追涨停、未确认首阴低吸、
纯 K 线形态单独触发。

## 五、AI 接入

`Data/AIClient.swift`，**OpenAI 兼容的 Chat Completions**，支持 OpenAI / DeepSeek / Moonshot / 通义 / 本地 Ollama 等所有兼容端点。

### 配置

界面右下「AI 接入」面板：启用开关、Base URL、API Key、模型名、每次送审只数。
Key 只存本机 `UserDefaults`，不外发。

### 让 AI 做什么

系统提示词把 AI 限定成**保守的短线风控分析师**：

```
1. 优先看风险再看收益。止损>8%、趋势向下、顶背离、放量滞涨 → 一律「回避」
2. 风险收益比 < 1.5 的机会不做。宁可错过，不要做错。
3. 只在三种情况给「买入/强烈买入」：
   - 回踩关键支撑不破且缩量（低吸）
   - 放量突破压力且趋势向上（突破）
   - 主力连续流入且价格处于相对低位（吸筹完成）
4. confidence 必须诚实，不要普遍给高分
5. 止损必须放在有效支撑下方，不能为了好看而缩小
```

输入是结构化的量化指标（现价、四类信号分、支撑压力、盈亏比、入场区间、主要依据），
输出是严格 JSON：`action / confidence / entryLow / entryHigh / stopLoss / target / positionPct / thesis / risks`。

### 实测验证

用模拟 OpenAI 端点完整跑通：
- 连通性测试 → 401 错误正确识别为「API Key 无效」
- 复核 3 只股票 → 正确解析出「买入/观察/回避」+ 止损/目标/仓位
- 结果与系统评分**同屏对照显示**，两方结论不一致时一眼可见

### 本地模型解释（Ollama，`Data/LocalLLM.swift` + `Core/SignalExplainer.swift`）

规则引擎永远是决策核心；本地模型只做**解释层**：输入是规则已算好的信号 JSON，
输出是自然语言说法，不参与决策、不新增信号。提示词铁律：只引用给定数字、不许编造、
不知道就拒绝、≤150 字；输出还要过数字校验（文本里的每个数字必须出现在输入 JSON 里，
否则回落模板）。**模板解释器永远可用**：按信号字段确定性生成中文推理文字，离线可用，
是"微型思维辅助"的基线。

默认关闭。想用先自己装 Ollama 并拉模型（本软件不捆绑、不下载模型）：

```bash
brew install ollama
ollama pull qwen2.5:3b
ollama serve   # 监听 http://localhost:11434
```

然后在「AI 接入」面板的「本地模型解释（Ollama）」区打开开关、填模型名、点「测试本地端点」。
8GB 内存只能跑 3B 级模型（qwen2.5:3b 约 1.9GB），7B 会换页卡顿。端点不通、超时、
输出校验失败时自动回落模板文字，界面会注明是模板解读。

**LLM 的诚实限制**：小模型会编造数字、算术不可靠、不能预测涨跌；数字校验只能拦住
"引用了输入里没有的数字"，拦不住"引用了输入数字但推理错误"。解释文字仅供参考，
一切以规则算出的数字为准。

## 七、支撑压力

`Core/Levels.swift`，五种独立证据源 + 聚类 + 加权：

1. **摆动点**：左右各 5 根局部极值
2. **成交密集区**：近 180 根分 60 箱累加成交量（筹码壁垒）
3. **均线**：MA20 / MA60 / MA120
4. **斐波那契**：近 120 根 0.236/0.382/0.5/0.618/0.786
5. **前高前低**

聚容差 2.2% + 二次合并，按**证据广度**打分：

```
基础 22 分（单一来源）
每多一种独立来源 +17 分
四种以上共振 +6
触碰次数 ×2.6（上限 8 次）
成交密集区 +5~14，均线汇聚 +2.5~7
±16% 距离带过滤
```

效果：单一斐波那契 ~25 分（弱），筹码+均线+摆动三重共振可到 100 分（极强）。
**这是相对强度，不是概率。**

## 九、交互设计（对照同花顺）

### 核心原则：查看 ≠ 收藏

这是主流行情软件的基本约定，本工具已完整实现：

| 操作 | 行为 |
|---|---|
| 搜索框输入 | 实时下拉结果，**不自动加入自选** |
| 点搜索结果整行 | **只切图预览**，结果列表收起，图表立刻更新 |
| 点搜索结果右侧 `+` | **加入自选**，图标变 `✓` |
| 回车（纯代码） | 代码直达预览，同时列出搜索结果 |
| 回车（中文/拼音） | 搜索并预览第一条，结果列表保留 |
| 头部 `+ 自选` / `★ 已自选` | 加入 / 移除当前标的 |
| 侧栏顶部提示条 | 当前标的未自选时出现，带 `+ 自选` 快捷按钮 |

### 状态模型

```
currentSecurity   ← 当前看图（可能是未自选的临时标的）
      ↓
watchlist         ← 自选列表（持久化）
      ↓
selectedID        ← 自选里被高亮的行（当前标的恰在自选时才有值）
```

三者解耦，所以「看一只没加自选的票」是合法状态，不会污染自选。

### 自选列表

| 操作 | 行为 |
|---|---|
| 点击行 | 切图 + 高亮 |
| 右键 | 从自选移除 / 置顶 / 复制代码 / 单独扫描 |
| 排序 | 手动 / 涨幅 / 跌幅 / 名称（顶部芯片切换） |
| `↑` `↓` | 上下切换标的 |
| `←` `→` | 切换周期 |
| `⌘F` / `⌘N` | 聚焦搜索框 |
| `⌘D` | 当前标的加入自选 |

### 已修复的坑

1. **中文名被误判成美股代码** —— `Character.isLetter` 对汉字返回 true，导致「五粮液」被当成 `us.五粮液`。改为只接受 ASCII 字母。
2. **手势识别器抢走 NSButton 点击** —— `NSClickGestureRecognizer` 挂在整行上会吞掉 `+` 按钮的事件。改用 `mouseDown` 手动按区域分派。
3. **tooltip 遮挡内容** —— 禁用状态的按钮仍会弹 tooltip，且残留窗口会阻塞辅助功能读取。全部移除。
4. **搜索结果区隐藏后仍占高度** —— 隐藏视图的高度约束没有同步归零，留下大片空白。改为高度约束与 `isHidden` 联动。
5. **快速切换标的时数据错乱** —— 旧请求晚于新请求返回会覆盖界面。加请求序号，过期响应直接丢弃。

```bash
cd QuantLens
./build_app.sh          # 编译 + 打包 + ad-hoc 签名
open dist/QuantLens.app
```

- Swift 5.9+（**Command Line Tools 即可，不需要 Xcode**）

### 测试与 CI

```bash
swift build               # 编译
swift test                # 单元测试（确定性合成夹具，不联网）
```

GitHub Actions（`.github/workflows/ci.yml`，macOS 14 runner）：每次 push / PR 自动跑
`swift build` + `swift test` + `./build_app.sh` 打包，并上传 `QuantLens.app` 产物（保留 7 天）。
测试以 `@testable import` 引用可执行 target，不拆模块；`main.swift` 在测试构建中被排除。

### 为什么用 AppKit 而不是 SwiftUI

CLT 的 SwiftUI 模块**缺宏插件**（`libSwiftUIMacros.dylib` 不存在），`@State`/`@Observable` 全部编译失败：

```
error: external macro implementation type 'SwiftUIMacros.StateMacro'
       could not be found for macro 'State()'
```

改用 AppKit 后，图表用 `CGContext` 手绘反而更可控（蜡烛宽度、价位对齐、标记位置都要精确控制）。

### 一个非显然的坑

`NSScrollView.documentView` 如果**没有初始 frame**，AutoLayout 首次布局会陷入无限递归，表现为应用启动后无窗口、CPU 空转。
必须给 `FlippedView(frame: NSRect(x:0,y:0,width:w,height:h))` 一个非零初始尺寸。

## 十二、已知限制

1. **分钟线仅沪深 A 股** —— 港美股接口不提供，切分钟周期自动回落日线
2. **港股/美股无资金流** —— 新浪资金流只覆盖 A 股，这两市场「主力进出」只剩 OBV/CMF/量价代理，信号偏弱
3. **免费接口无 SLA** —— 东财已实测限流；腾讯/新浪目前稳定但不能保证长期。接口集中在 `Data/` 三个文件，改起来方便
4. **AI 只做复核不做决策** —— 最终买卖由人判断，AI 结论与系统评分同屏对照
5. **不做实盘下单** —— 纯分析工具，无任何交易接口
6. **扫描是逐只拉取** —— 自选股很多时耗时会线性增长（16 只约 13 秒）
7. **实时买点榜仅 A 股** —— 港美股无分时接口，不进入买点榜；日线扫描与信号不受影响
8. **交易时段判断无节假日表** —— 只排除周末；节假日当天数据静态，榜单不会产生新触发，但状态文字仍显示为交易时段轮询
9. **情绪宽度依赖排行字段** —— 新浪排行接口的 `changepercent/high/low/trade` 字段缺失时自动降级（涨跌幅改用现价/昨收推算，炸板率记 0 不参与判定）；连板高度无字段来源，不统计，以涨停家数 + 强势股占比代理
10. **竞价委买比只在采样响应含五档时有效** —— 无五档字段时委买比为 0，不加分不扣分；昨日基因复核只覆盖评分前 25 名
11. **买卖点组合策略未经 OOS 回测** —— 十个检测器各有规则依据，但组合表现未经样本外验证，不宣称收益或胜率；B6 首阴反包样本依据极弱（仅 7 笔），只作最小仓位级别观察
12. **门控指数趋势每天最多刷新一次** —— 当日首次情绪刷新时拉取上证指数日线；门控变化后需下次加载标的才生效，不自动重算当前图

## 十三、风险声明

这个工具**不保证赚钱**，也不构成投资建议。

它的价值在于：
- 把「风险收益比」「止损位」「支撑压力」这些容易被忽略的东西**量化并摆到眼前**
- 用回测告诉你**哪些信号在哪些股票上不可靠**
- 用 AI 做一次独立的第二意见
- 把市场的贪婪与恐惧量化成可比较的分数与相位，帮你**观察情绪周期**，而不是替你判断买卖

短线交易的真实胜率取决于纪律，不是信号。**任何单一信号都不该成为买入的唯一理由。**
情绪信号、竞价评分、机会榜排名都是观察工具，**不构成任何投资建议**。
